Launch Radar

Protocols that record no token, ranked by what a token would be worth if the record stayed as it is. The board finds launches before they happen — and shows how to farm each one.

How the value is worked out

implied value = TVL × peer multiple × growth × maturity × breadth

  • Peer multiple. The median market-cap-to-TVL ratio of the live-token protocols in the same category, taken from this same snapshot. No flat multiple, no hand-picked names.
  • Growth. The 7-day TVL change, clamped to −80% … +150%, weighted 0.60.
  • Maturity. How long the protocol has run with no token recorded: 0.70 at day zero, rising to 1.20 after four years.
  • Breadth. 2% per chain it runs on, up to five chains.

A protocol is listed as pre-token when its record carries no token — no market cap, no CoinGecko id, no symbol. That is what the record says, never proof it has none. Live-token protocols are shown apart, with the market’s own values, never mixed into the ranking.
